# 03 · AI 能力：core/analyst

平台保留 AI 分析师能力：LLM 负责选择工具和组织语言，所有经营数字由 Python 工具确定性计算。

## AI 分析师 `core/analyst/`

### `llm.py` — 统一 LLM 客户端

封装 OpenAI 兼容接口，默认使用 DeepSeek。配置来源为 `.env` 优先，其次是 `config.yaml` 的 `analyst` 节。

主要能力包括连接配置读取、模型调用、流式调用、超时控制和常见错误转换。

### `tools.py` — 数据工具集

分析师可调用以下工具查询和分析已采集数据：

| 工具 | 职责 |
|---|---|
| `query_summary` | 按日期、场地和平台查询收入数据 |
| `dashboard_snapshot` | 读取经营大屏快照 |
| `forecast` | 生成月度完成率和趋势预测 |
| `detect_anomaly` | 检查单日收入异常 |

涉及数字时，系统要求先调用数据工具，禁止模型直接编造数字。

### `agent.py` — Agent 编排器

会话保存在 `analyst_sessions` 和 `analyst_messages` 两张表中。支持同步问答和 SSE 流式问答，工具调用有最大轮数限制。

### `forecast.py` — 预测引擎

使用 numpy 和已入库数据进行月度完成率推演、趋势预测和异常检测。该模块不依赖自然语言生成表格功能。
