# 08 · 数据存储设计

平台共三类存储：**本地 SQLite**（业务主库）、**外部 MySQL**（只读场地映射）、**文件系统**（凭证密钥/Cookie/下载缓存/目标表/日志）。

## 8.1 SQLite 主库 `data/app.db`

连接特性（`core/db.py::get_connection`）：WAL 模式、外键 ON、`row_factory=sqlite3.Row`、每次调用新建连接。

### 完整表结构（init_db 建表语句）

**tasks — 任务状态表**

```sql
CREATE TABLE IF NOT EXISTS tasks (
    id           TEXT PRIMARY KEY,          -- uuid4
    platform     TEXT NOT NULL,
    date         TEXT NOT NULL,             -- 采集日期
    venue        TEXT DEFAULT '',
    status       TEXT NOT NULL DEFAULT 'pending',  -- pending/running/success/failed
    step         TEXT,
    progress     INTEGER DEFAULT 0,
    started_at   TIMESTAMP,
    finished_at  TIMESTAMP,
    created_at   TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    retry_count  INTEGER DEFAULT 0,
    error_msg    TEXT
);
CREATE INDEX IF NOT EXISTS idx_tasks_date ON tasks(date);
CREATE INDEX IF NOT EXISTS idx_tasks_status ON tasks(status);
```

**daily_summary — 汇总数据长表（核心业务表）**

```sql
CREATE TABLE IF NOT EXISTS daily_summary (
    id            TEXT PRIMARY KEY,         -- uuid4
    date          TEXT NOT NULL,
    venue         TEXT NOT NULL,            -- 场地
    platform      TEXT NOT NULL,
    metrics_json  TEXT NOT NULL,            -- 指标字典 JSON
    raw_file      TEXT,
    period_start  TEXT,                     -- 本次累计采集开始日期
    source_task_id TEXT,                    -- 写入该快照的任务
    updated_at    TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(date, venue, platform)           -- UPSERT 幂等键
);
CREATE INDEX IF NOT EXISTS idx_summary_date ON daily_summary(date);
```

**scheduled_collection_runs — 经营数据自动采集批次**

```sql
CREATE TABLE IF NOT EXISTS scheduled_collection_runs (
    id              TEXT PRIMARY KEY,
    job_key         TEXT NOT NULL UNIQUE,
    slot_key        TEXT NOT NULL,
    slot_label      TEXT NOT NULL,
    target_date     TEXT NOT NULL,
    scheduled_for   TIMESTAMP NOT NULL,
    status          TEXT NOT NULL DEFAULT 'pending',
    total_tasks     INTEGER NOT NULL DEFAULT 0,
    success_count   INTEGER NOT NULL DEFAULT 0,
    failed_count    INTEGER NOT NULL DEFAULT 0,
    retry_count     INTEGER NOT NULL DEFAULT 0,
    started_at      TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    finished_at     TIMESTAMP,
    message         TEXT DEFAULT ''
);
CREATE INDEX IF NOT EXISTS idx_scheduled_collection_runs_time
    ON scheduled_collection_runs(scheduled_for DESC);
CREATE INDEX IF NOT EXISTS idx_scheduled_collection_runs_status
    ON scheduled_collection_runs(status);
```

- `job_key=<slot_key>:<排程日期>`，例如 `yesterday-final:2026-08-25`。唯一约束配合 `BEGIN IMMEDIATE` 使同一时段在服务重启或多进程同时检查时只能被一次领取。
- `target_date` 是月累计采集的截止日；新任务同时记录 `start_date`，正常值为目标月份1日。
- 运行中使用 `pending` / `running`；正常终态为 `success` / `partial` / `failed`，服务中断后为 `expired`。
- 服务启动时将遗留 pending/running 批次标记为 `expired`；同一 job_key 再补跑时复用该记录并增加 `retry_count`。
- 表内是“排程批次”状态；每个平台的详细任务和错误仍保存在 `tasks`，真实业务数据仍保存在 `daily_summary`。

**credentials — 凭证元信息表（明文密文在 encrypted_value）**

```sql
CREATE TABLE IF NOT EXISTS credentials (
    platform        TEXT PRIMARY KEY,
    encrypted_value TEXT NOT NULL,          -- Fernet 加密的凭证 JSON
    status          TEXT DEFAULT 'unknown', -- active/expired/unknown
    last_check_at   TIMESTAMP,
    last_success_at TIMESTAMP,
    updated_at      TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

**users — 企业内部账号与权限**

```sql
CREATE TABLE IF NOT EXISTS users (
    id               TEXT PRIMARY KEY,
    username         TEXT NOT NULL UNIQUE COLLATE NOCASE,
    display_name     TEXT NOT NULL,
    password_hash    TEXT NOT NULL,          -- PBKDF2-SHA256 独立盐化哈希
    permissions_json TEXT NOT NULL DEFAULT '[]',
    scope_type       TEXT NOT NULL DEFAULT 'all', -- all / venues
    venue_scope_json TEXT NOT NULL DEFAULT '[]',  -- 指定门店名称数组
    is_active        INTEGER NOT NULL DEFAULT 1,
    last_login_at    TIMESTAMP,
    created_at       TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at       TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

**auth_sessions — 登录会话**

```sql
CREATE TABLE IF NOT EXISTS auth_sessions (
    token_hash TEXT PRIMARY KEY,              -- 浏览器随机令牌的 SHA-256，不存原令牌
    user_id    TEXT NOT NULL,
    csrf_token TEXT NOT NULL,
    expires_at TIMESTAMP NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY(user_id) REFERENCES users(id) ON DELETE CASCADE
);
```

会话默认有效 12 小时；停用账号、修改权限或重置密码会立即删除该用户已有会话。Cookie 只保存随机原令牌，并设置 HttpOnly、SameSite=Strict。

**analyst_sessions — AI 分析师会话**

```sql
CREATE TABLE IF NOT EXISTS analyst_sessions (
    id         TEXT PRIMARY KEY,
    title      TEXT DEFAULT '新对话',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

**analyst_messages — AI 分析师消息**

```sql
CREATE TABLE IF NOT EXISTS analyst_messages (
    id         INTEGER PRIMARY KEY AUTOINCREMENT,
    session_id TEXT NOT NULL,
    role       TEXT NOT NULL,               -- user/assistant/tool
    content    TEXT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX IF NOT EXISTS idx_analyst_messages_session ON analyst_messages(session_id);
```

**entry_payment_revisions — 进场货款修订记录**

```sql
CREATE TABLE IF NOT EXISTS entry_payment_revisions (
    id            INTEGER PRIMARY KEY AUTOINCREMENT,
    venue         TEXT NOT NULL,
    revision      INTEGER NOT NULL,
    entry_date    TEXT NOT NULL,
    amount_cents  INTEGER NOT NULL CHECK (amount_cents >= 0),
    note          TEXT NOT NULL DEFAULT '',
    actor_user_id TEXT NOT NULL DEFAULT '',
    created_at    TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(venue, revision)
);
```

金额按分保存；同一门店每次修改追加一个 `revision`，页面读取最新版本，历史修订不覆盖。标准门店来自数据看板的场地/负责人清单。

## 8.2 数据口径（重要）

**daily_summary.metrics_json 存的是「当月累计值」**：

- 单日值 = 当日累计 − 前一自然日累计（`core.daily_operations` 严格校验相邻日期）
- 跨月重置：月内首个采集日的单日值 = 该日累计自身（不减上月末）
- 货款累计汇总的积分 = 每个已结束月份最后一个自然日的各平台（积分增加 − 积分减少）之和 × 1.5 元；不累加每日快照，也不回退到月内更早日期
- **收入汇总口径**：`crawlers/report_summary.py::INCOME_COLUMNS`（17 列求和，已剔除 Kpay收款）——全系统唯一权威定义处

`daily_summary.updated_at` 是门户展示的真实入库时间来源。`period_start` 为空的旧记录属于历史口径未验证数据，不能直接作为正式每日数据；`GET /api/daily-operations` 会返回缺失、范围未知和平台缺行状态。

> `scheduled_collection_runs` 只对经营汇总排程生效。多金宝会员资产自动监控使用独立的 `monitor_sync_runs` 和 `monitor_events`，两者的时段、结果和防重不可混用。

## 8.3 外部 MySQL `store_mapping_db`（只读）

配置：`config.yaml` mysql 节 + `.env` `MYSQL_PASSWORD`（环境变量优先）。连接参数：utf8mb4 / connect_timeout=10 / read_timeout=30 / write_timeout=30。

| 表 | 用途 | 使用方 |
|----|------|--------|
| `company_organizational_structure` | 平台店铺名 → 场地映射（每平台一列，见 [05-爬虫层](05-爬虫层crawlers.md) 映射总表） | 12 个平台爬虫/匹配器 |
| `table_sequence_config` | 汇总表列定义与排序（id/system_tag/column_alias） | report_summary |
| `principal` | 场地负责人（person_in_charge_id 关联） | report_summary |

**只读保证**：全部爬虫对 MySQL 无任何 INSERT/UPDATE/DELETE。

**连接方式现状**：meituan_match 走 `utils/mysql_pool`（VenueMapCache TTL 3600s 缓存）；其余各自 `pymysql.connect` 直连（连接池已建但未全面接入，已知技术债）。

## 8.4 文件系统存储

| 路径 | 内容 | 说明 |
|------|------|------|
| `credentials/.fernet_key` | Fernet 主密钥 | 首次运行自动生成；**丢失则全部凭证不可解密** |
| `credentials/douyin/` | cookie_header.txt / cookies.json / storage_state.json / browser_profile/ | 抖音登录态（完整 Chromium 指纹目录） |
| `data/targets/*.xlsx` | 月度目标表 | 「最终核定」列 = 门店目标（config `targets.file`，缺失时取目录最新 xlsx） |
| `data/targets/regions.json` | 门店 → 区域映射 | 6 区域：香港/深圳/广州/江门/福州/东莞 |
| `data/downloads/meituan/` | 美团下载 Excel 缓存 | 文件名含店铺 ID/日期区间/任务号；同日重复采集有本地缓存复用逻辑 |
| `data/logs/` | `app_fastapi.out/err.log` + 按启动时间戳轮转的历史日志 | stdout/stderr 重定向 |
| `data/coin_exchange.json` | 八爪鱼导出的兑币机数据 | fetch_mode=file/auto 兜底数据源 |
| `data/2025-2026_营收数据汇总.xlsx` | build_excel.py 产物 | 一次性财务汇总表（硬编码数据） |
| 本地 CSV/Excel 源 | 八达通 report.csv（E 盘八爪鱼目录）、门店货款数据.xlsx（C 盘公司数据） | local_csv / local_excel 型平台的数据源，config 可改路径 |

## 8.5 备份策略

- 手动复制 `data/` 目录（RPO ≤ 1 天，RTO ≤ 15 分钟）
- `credentials/.fernet_key` 必须与 `data/app.db` 一并备份（否则凭证不可恢复）
- WAL 模式保证崩溃恢复一致性
