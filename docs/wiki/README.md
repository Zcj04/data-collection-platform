## 一分钟了解本项目

本平台是面向数据专员的 **Windows 单机经营数据采集中枢**：将原先依靠八爪鱼 RPA + 散装 Python 脚本、每天耗时 1~2 小时的手工采集流程，整合为「一页看板 + 一键采集」的自动化工作台。

- **采集**：13 个平台并行采集，默认按 `Asia/Shanghai` 每日 10:10 拉取目标月 1 日至昨日的正式累计数据，不采集当天未结束数据；服务晚启动可补跑，管理员保留手动兜底
- **存储**：采集结果 UPSERT 进本地 SQLite（`data/app.db`），平台账号凭证 Fernet 加密存储；只读外部 MySQL（`store_mapping_db`）做店铺名→场地映射
- **账号**：首次在本机 `/setup` 创建超级管理员；以后从 `/login` 登录，使用 HttpOnly 数据库 Session 和八项模块权限保护门户、后台及新旧 API
- **消费**：数据看板 / 数据大屏（月度目标完成度）/ 每日经营数据 / Excel 导出
- **新鲜度**：门户展示真实入库时间、13 源覆盖与下次运行；仅 `portal.view` 的用户不能触发采集
- **AI**：AI 分析师（DeepSeek 工具调用 Agent，问答式经营分析）

## 架构速览

```
┌─────────────────────────────────────────────────────────┐
│  表现层  login / portal / dashboard（原生 HTML/JS）     │
├─────────────────────────────────────────────────────────┤
│  服务层  FastAPI + 认证/RBAC + Portal/Admin API         │
├──────────────┬──────────────────┬───────────────────────┤
│  调度 core/  │  AI core/analyst                         │
│  scheduler   │  agent+llm+tools                         │
│  task_mgr    │  forecast                                │
├──────────────┴──────────────────────────────────────────┤
│  适配层  adapters/（ABC 基类 + factory + 13 个适配器）   │
├─────────────────────────────────────────────────────────┤
│  爬虫层  crawlers/（18 个脚本，核心逻辑保持原始零改动）  │
├─────────────────────────────────────────────────────────┤
│  存储：SQLite(WAL) 业务数据/用户/Session │ 只读 MySQL   │
│        Fernet 加密凭证 credentials/                     │
└─────────────────────────────────────────────────────────┘
```
