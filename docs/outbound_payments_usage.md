# 出货货款模块

已于 2026-08-31 接入本地系统。入口：管理员后台 → 货款账册 → 出货货款。

## 当前可查看的数据

2026 年 7 月已通过正式模块重新采集并保存完整版本：31/31 天、N条库存流水、10 家有流水门店；设备出礼 N条、N件、已记录成本 N.57元。5 条零成本出礼列为待核对。7月明细中盘点、调拨、初始化与清零未混入出礼成本。

这只是“示例品牌”总部可见设备库存报表的成本。平台提供预估成本，不直接等于最终核定货款；目前没有并入累计货款公式。

## 使用方式

1. 在“报表月份”选择已结束的自然月，默认打开最近已有完整数据的月份。月份切换时采集起止月份同步到所选月。
2. 通过门店选择器或点击表格店名，只看该店的成本、数量和每日记录；选“全部有流水门店”恢复总部报表。
3. 点击每日方格查看当天明细。灰色“无源记录”显示为 `—`，不能认定为零出货。
4. 明细可切换源流水、按商品汇总、按设备汇总；商品和有终端编号的设备可继续点“查看流水”。设备缺少编号时仅展示来源门店内的同名设备汇总，不与其他店合并，也不捏造设备 ID。
5. 选择“库存调整（不含出礼）”查看盘盈、盘亏、调拨等；明细数量和金额保留平台原始正负号。
6. 勾选“仅看待核对”或点击门店零成本入口，查看零成本、金额/数量异常、未知类型和门店匹配问题。明细每页50条，后端分页。
7. 展开“逐月出货概览”查看该门店或全部门店每月数据。只有7月数据时不显示虚构环比。

## 采集与重采

展开“按月采集与任务记录”，选择起止月份，点击“开始按月采集”。单月时起止选择同一个月；多个月份按顺序执行，每月逐日分页。

总部凭证保存在“凭证管理 → 多金宝 → 总部账号 / 总部密码”，使用现有加密存储；它与普通单一采集账号相互独立。页面只显示配置状态，不回显密码或账号值。

- 第一版只接受已结束月份，8月最早9月1日采集为完整自然月。
- 重采期间保留旧完整版本；新月份全部日期成功且总数/金额对账通过，才在事务内切换版本，不与旧数据叠加。
- 同一时间只运行一组出货任务，避免总部会话交叉。失败后不继续逐月重复登录，后续月份停止并保留重试入口。
- “停止该批次”会停止该组中正在运行和排队的月份；正在进行的网络请求最多等待自身超时，不再落库或发布。
- “重试剩余日期”保留该月已完整保存的日期，从剩余日期重新读取。服务重启会将中断任务标为未完成，不误报成功。
- 若更换总部或账号，旧批次不允许混用先前日期，应重新采集整个自然月。标准门店映射也在批次开始时冻结，重试不悄悄换映射。

## 数据核对

“31/31 天采集完整”和“5 条成本待核对”可以同时存在，前者表示源报表取数完整，后者表示需要业务判断。

- 深H商圈5条出礼成本为0，商品为“抓机品”；保留原值，不用其他交易价格补价。
- 广州A商圈有26个日期无任何库存流水，另有1天只有库存变更、4天有出礼；没有据此推定开业日期或零出货。
- 总部组织清单当前可访问12家门店，本月报表仅出现10家；另外2家无源记录，不填0。该范围不代表全公司其他平台门店全部覆盖。
- 源店名精确且唯一匹配标准门店才挂接；歧义和未知门店仍保留原始流水并提示待处理。历史流水不会因当前撤店状态而删除。
