## 电脑、手机及平板

Chromium 使用当前源码模板与本地静态文件进行离线仿真。6 个宽度：360、390、768、920、1366、1920；每个宽度检查登录、门户 6 个栏目、后台 5 个栏目，共 **72 个组合**，无整页横向溢出、无未捕获 JavaScript 异常。人工查看了手机汇总、手机用户管理、桌面用户管理截图。

门户手机汇总采用门店卡片，后台用户管理在手机变为上下排布；宽账表保留容器内横向滚动，因此手机适合查看和轻量维护，密集核算仍更适合电脑。

2. **入口防护**：应用登录失败按 IP+用户名组合限流，不能阻挡轮换用户名的总体流量；上传限制主要在解析阶段。模板补充请求体上限，实际入口仍需验证分块大请求、并发/超时策略和可信代理头。未经这些验证，不建议直接开放公网。
