# 新电脑部署指南

> 本仓库为完整打包版本：代码 + 离线依赖 + 凭据 + 数据库快照全部包含，按以下步骤恢复即可使用。

## 1. 前置环境（仅 3 样，仓库无法携带）

| 依赖 | 要求 | 说明 |
|---|---|---|
| Python | **3.13 64位**（必须） | `_pylib` 内编译包为 cp313 版本，其他版本无法运行 |
| MySQL | 8.0 | 门店映射库（store_mapping_db）需按第 3 步恢复 |
| Git | 任意新版 | clone 用 |

## 2. 拉取代码

```bash
git clone https://github.com/Zcj04/data-collection-platform-2.git
cd data-collection-platform-2
```

> 若报 `schannel: 吊销功能无法检查证书是否吊销`（国内网络常见），改用：
> ```bash
> git -c http.sslBackend=schannel -c http.schannelCheckRevoke=false clone https://github.com/Zcj04/data-collection-platform-2.git
> ```

## 3. 恢复数据库

**3.1 主数据库 app.db（含已保存的各平台登录凭据）：**

```bash
python -c "import zipfile; zipfile.ZipFile('data/app.db.snapshot.zip').extractall('data')"
```

**3.2 MySQL 门店映射库（需已安装 MySQL 8.0，且 root 密码与 .env 中一致）：**

```bash
"C:/Program Files/MySQL/MySQL Server 8.0/bin/mysql.exe" -uroot -p < data/mysql_store_mapping_db.sql
```

**3.3 Playwright 浏览器内核（约 150MB 下载，爬虫功能需要）：**

```bash
python -m playwright install chromium
```

## 4. 启动

```bash
python app_fastapi.py
# 或使用 start_service_nosandbox.bat
```

启动后访问 http://127.0.0.1:8010

## 常见问题

- **`_pylib` 如何生效？** 项目通过 `runtime_bootstrap.py` 自动把 `_pylib` 加入模块搜索路径，无需 pip install、无需 venv。
- **凭据解密失败？** 确认 `credentials/.fernet_key` 存在（已包含在仓库中），且 app.db 已按 3.1 步骤恢复。
- **MySQL 密码不同？** 修改 `.env` 中的 `MYSQL_PASSWORD` 后再用第 3.2 步导入。
