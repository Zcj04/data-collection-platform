## 一、它的技术栈与整体风格

| 维度 | 油菜花的做法 |
|------|--------------|
| 前端框架 | umi + React + **Ant Design v5 + Ant Design Pro 布局** |
| 图表 | ECharts 风格（折线图、环形图） |
| 配色 | 主色 Ant 蓝 `#1677ff`；侧边栏**深海军蓝**（带图标+分组），内容区白底浅灰背景 `#f5f7fa` |
| 布局 | 左侧固定侧边栏（可折叠）+ 顶栏 + **多标签页导航**（打开的页面像浏览器 tab 一样可关闭） |
| 卡片 | 白底、8px 圆角、细边框浅阴影、标题右侧带 ⓘ tooltip |
| 数字 | 关键指标大字号蓝色，涨跌带红/绿箭头 + 百分比 |

### 值得抄的 6 个设计点

1. **顶部 KPI 指标卡行**（首页）：左两张大卡（营业收入·实时 / 本月收入，带同比涨跌和完成率），右边一排小卡（币客单、币单价、耗币数、新增会员、存彩票、游玩人次、线上核销、售币数…）。
2. **日期快捷条**：`今日 / 昨日 / 本月 / 上月 / 今年` 一键切换 + 日期区间选择器 + 刷新按钮，全局统一。
3. **多标签页导航**：点菜单开新 tab，顶部 tab 可切换/关闭，报表对照着看很方便。
4. **表格规范**：数字列右对齐、排序箭头、小计/合计行加粗置底、斑马纹、横向滚动、右上角「导出」按钮、底部分页器。
5. **图表联动切换**：「门店关键指标」折线图可切 收入/会员/耗币 三个维度；环形图可切 金额/币数。
6. **卡片墙看板**（夹机看板）：每台机器一张图卡（图片 + 出礼数 + 启动周数 + 毛利率），顶部一排 KPI——这个形式非常适合做**采集任务状态墙**。

## 二、迁移到你的平台（FastAPI + Jinja2 + Alpine.js + Tabler）

Tabler 与 Ant Design 组件形态高度相似，改造以「借布局、借交互、换配色」为主，不动后端：

| 改造项 | 做法 | 工作量 |
|--------|------|--------|
| 侧边栏深蓝渐变 + 分组菜单 | Tabler 侧栏加自定义 CSS：`linear-gradient(180deg,#1b2a4e,#16223f)`，菜单按 采集/报表/设置 分组（对应它的 游乐/设置 分组） | 小 |
| 顶部 KPI 卡片行 | Tabler card + 大字号数字；同比涨跌用红涨绿跌（你的数据统计口径） | 小 |
| 日期快捷条 | Alpine.js 按钮 group（今日/昨日/本周/本月/今年）联动你已有的日期选择器记忆 | 小 |
| 表格规范 | 斑马纹 + 合计行 + 数字右对齐 + 表头排序（纯 JS 可做）+ 导出按钮（你已有 build_excel） | 中 |
| ECharts 图表区 | 首页/dashboard 引入 echarts CDN，图表容器随卡片 | 中 |
| 多标签页导航 | Tabler tabs + localStorage 记忆打开的页面 | 大（可放最后） |

## 三、基于你的数据能做的图表（对应油菜花页面）

你的数据源：`daily_summary`（UNIQUE(date, venue, platform)，总收入/总货款等衍生指标）、`company_organizational_structure`（49 家门店、区域）、11+ 平台。

| # | 图表 | 类型 | 对应油菜花页面 | 数据来源 |
|---|------|------|----------------|----------|
| 1 | **营业收入趋势**（按日，可切 总收入/总货款） | 折线图 | 首页·门店关键指标 | daily_summary 按日期聚合 |
| 2 | **平台收入占比**（美团/抖音/芸苔/乐摇摇…TOP N + 其他） | 环形图 | 首页·币售卖情况 | daily_summary 按 platform 聚合 |
| 3 | **门店收入 TOP10 排名** | 横向条形图 | （区域报表思想） | daily_summary 按 venue 聚合 |
| 4 | **门店 × 平台 交叉汇总表**（行=门店，列=平台，行/列小计+合计） | 表格 | 区域报表·收银一览 | daily_summary pivot |
| 5 | **本月 vs 上月 对比**（各平台收入双柱/双折线） | 柱状图 | 项目消费月对比 | daily_summary 两个月份对比 |
| 6 | **今日实时 KPI 卡**（今日收入·实时 / 本月累计 + 环比涨跌%） | 指标卡 | 首页顶部 KPI 行 | daily_summary 当日 + 月累计 |
| 7 | **采集任务状态墙**（每平台一卡：今日状态/最后成功时间/失败重试按钮） | 卡片墙 | 夹机看板 | 采集任务元数据 |
| 8 | **渠道收入一览**（线上平台 vs 线下收银分类） | 汇总表 | 渠道报表 | platform 归类映射 |

> 优先级建议：先做 1、2、6（首页一屏看完大盘），再做 3、4（你提交日报最常用的门店/平台视角），7 采集看板作为平台特色功能。

## 四、分期实施建议

- **第一期（样式对齐）**：侧边栏深蓝渐变 + 分组菜单、首页 KPI 卡片行、日期快捷条、表格规范统一。
- **第二期（图表丰富）**：ECharts 接入，上 趋势折线图 + 平台占比环形图 + 门店 TOP 条形图（数据接口用现有 FastAPI 加 3 个 `/api/charts/*` 端点）。
- **第三期（体验增强）**：多标签页导航、采集任务状态墙、图表维度切换（收入/货款）。
