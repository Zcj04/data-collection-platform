# 会员追踪与核查线索

入口：后台「数据监控」以及普通门户「数据监控」。沿用 monitoring.view 权限和服务端门店范围，未新增权限或业务库表。

在当前筛选范围内，按来源、门店、会员标识分组；展开后按具体资产和单位查看充值、赠送、消费、退款与调整净额。缺少会员标识及“匿名会员”不参与分组。指定日期仍沿用原监控接口的单日口径。只展示前100个分组，优先排列线索数和流水数较多者，并标明截断；后台可用现有门店和资产筛选缩小范围。

初始核查规则（不是已验证的反作弊阈值）：

- 同来源、同门店、同会员、同资产的滚动10分钟内，正向赠送至少3笔。
- 高频消费属娃娃机正常使用行为，不再触发会员提醒。
- 同组凌晨00:00至06:00（不含06:00）的消费，按源平台时间核查；已明确为转账、扣减、注销等记录不作为夜间消费。
- 明确标记“转账”或“转赠”的币类流水，单笔绝对值至少1000，暂作大额核查线；转换转入不归为转赠。转入和转出在会员资产明细中单独统计，不合并为消费。
- 管理后台赠送逐项待核查，包括未达到集中赠送频次的单笔赠送。
- 用户确认单笔1000币和凌晨0—6点范围。补充小额多笔核查：所选期间内，同方向多笔单笔不足1000币累计达到1000币，或同方向至少3笔，分别对转入和转出提醒；不以转入转出相抵后的净额判断。同一流水可能触发多项线索。
- 管理后台渠道的调整记录待核对；这是授权核查线索，不表示调整一定异常。

每项线索展示对应资产、次数及开始/结束时间，频次规则展示区间内笔数最多的窗口，不把重叠窗口重复计为多项线索。跨来源、门店、会员和资产不拼接。币和积分并列展示，不在兑换规则缺失时推断刷分率。没有触发规则不能证明不存在异常，采集缺失也会使频次偏低。

会员币值口径已确认：会员实付人民币÷获得币数。当前响应保留 coin_value=null、missing_payment_data；页面显示缺少实付数据。0.6元/币仅为用户提供的业务参考，未启用低币值告警，未将充值币数当成人民币。

现有单笔后台赠送、调整、负余额和统计异常提示继续保留；新面板统计的是会员分组，旧卡片统计的是单笔事件，因此数量不必一致。
